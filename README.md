# Binance-bot (Multi-Coin 15m Simulator)

Binance Futures **tüm USDT perpetual** coinleri tarayan sanal işlem botu.

> **Gerçek emir YOK** · API anahtarı YOK · Aynı sinyal mantığı korundu

## Özellikler

- **Tüm USDT-M perpetual** coinler dinamik taranır (≈500+)
- Orijinal sinyal mantığı: BB + StochRSI + KDJ + EMA5/20 + MACD + Hacim
- Sanal bakiye: **500 USDT**
- Her pozisyon: **10 USDT margin** + 10x kaldıraç (100 USDT notional)
- ATR tabanlı Stop-Loss
- Gösterge dönüşü ile Take-Profit
- Telegram bildirim
- Rate-limit korumalı tarama
